# Отчёт проверки Telegram Connected Business Bot

Статус: **в работе**. Автоматизированная часть коннектора реализована; испытание
на настоящем аккаунте ещё не проведено. Этот документ нельзя переводить в
состояние «пройдено» по результатам файлов-примеров или поддельного HTTP-клиента.

## Условия проверки

- бот разработки создан через BotFather и для него включён Business Mode;
- российский Telegram-аккаунт без Premium подключён к боту;
- API LidRadar доступен Telegram по постоянному или испытательному HTTPS-адресу;
- токен бота передан только через запрос подключения и не записан в репозиторий;
- для клиента, владельца и тестового получателя уведомления используются
  отдельные учётные записи там, где это требуется сценарием.

## Автоматизированная готовность

- `setWebhook`, `getWebhookInfo` и `deleteWebhook` проверяются без обращения в
  интернет через управляемый HTTP-клиент;
- секрет webhook передаётся Telegram как `secret_token`, а входящий заголовок
  проверяется до записи события;
- токен шифруется AES-256-GCM с привязкой к организации и подключению;
- ответы и ошибки не содержат токен;
- обрабатываются `business_connection`, `business_message`,
  `edited_business_message`, `deleted_business_messages`;
- повтор `update_id` дедуплицируется ограничением PostgreSQL.

## Итоговое решение

Заполняется только после живой проверки:

```text
P0 = Connected Business Bot
fallback = Standard Bot
```
