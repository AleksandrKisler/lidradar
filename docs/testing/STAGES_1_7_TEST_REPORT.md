# Отчёт о проверке этапов 1–7

Дата: 25 августа 2026 года.

## Итог

Все выполненные автоматические проверки прошли. Ошибок гонки данных,
нарушений границ модулей, потери очереди, создания второй активной Opportunity
или частичной записи при проверенных сбоях не обнаружено.

переписки при невозможности записать её outbox-событие.

## Враждебный ввод

Система предсказуемо отвергла чрезмерные тела, несколько JSON-документов,
неизвестные поля, неверные типы, неверный UTF-8, `U+0000`, SQL-подобные строки,
неверный tenant UUID, недоверенный Origin и неподписанный webhook. Опасный
`X-Request-ID` не отражается обратно. Корректно подписанный, но непригодный
webhook сохраняется для аудита как `FAILED` и не создаёт Conversation либо
Opportunity.

Во время проверки были устранены два найденных пограничных дефекта:

1. неверный `X-Tenant-ID` теперь отсекается общей HTTP-границей до SQL;
2. JSON с неверным UTF-8 или нулевым символом больше не может вызвать внутреннюю
   ошибку PostgreSQL.

## Измеренная местная нагрузка

Среда: локальный PostgreSQL в Docker, один процесс тестов, без внешней сети.

| Сценарий | Результат |
|---|---|
| 150 параллельных webhook | 150 RawEvent и 150 outbox; всего 156 мс; p50 94 мс; p95 150 мс; максимум 155 мс |
| 120 конкурентных кандидатов | 1 Opportunity и 1 история; всего 58 мс; p50 42 мс; p95 56 мс; максимум 57 мс |
| 300 заданий, 12 обработчиков | 300 `SUCCEEDED`, 0 повторных захватов; 149 мс; около 2 016 заданий/с |

Значения не являются обещанием производительности: они подтверждают
корректность под коротким параллельным всплеском на машине разработчика.
Длительная проверка с целевым объёмом, ограничением частоты запросов, наблюдением
за памятью и деградацией зависимостей остаётся входным условием пилота.

## Не покрыто автоматически

- реальный Telegram с двумя независимыми сторонами диалога — синтетический шаг
  ранее осознанно пропущен владельцем проекта;
- локальный AI Server — этап 7 его не вызывает;
- распределённая атака и проверка предельной пропускной способности — это
  отдельная эксплуатационная проверка перед пилотом;
- текущие контейнеры приложения не перестраивались и не перезапускались: тесты
  применяли миграции в изолированных временных схемах PostgreSQL.
