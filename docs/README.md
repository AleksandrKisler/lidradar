## Что не считается доказанной готовностью

Наличие описания endpoint, статуса `Accepted` у ADR или старого отчёта «пройдено»
не подтверждает соответствие конкретной текущей сборки. Пока release manifest,
обязательные внешние артефакты и относящиеся к выпуску gates не подтверждены,
общий статус комплекта для production: `NOT_VERIFIED`.

Исторический аудит сохранён как [снимок до исправлений](audit/LidRadar-docs-audit-and-migration.pplx.md).
Его цитаты относятся к прежней редакции; текущее состояние замечаний находится
в реестре исправлений, а не выводится из старых номеров строк.
