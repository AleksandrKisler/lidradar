# LidRadar

LidRadar — модульный монолит на Go. Единственным достоверным хранилищем
долговременного состояния является PostgreSQL.

Разработку серверной части следует начинать с [описания устройства](backend/README.md),
[архитектуры](docs/architecture/ARCHITECTURE.md), [явных запретов MVP](docs/architecture/NON_GOALS.md)
и [аудита выполнения задач](DONE.md).

Полный комплект технической документации серверной части (обзор, архитектура,
модули, API, модель данных, фоновая обработка, AI, защищённость,
отказоустойчивость, эксплуатация, тестирование) — в
[`docs/backend/`](docs/backend/README.md).

Для разработки интерфейса: [отдельный локальный бэкенд, три учебных пользователя
и обратимая миграция данных](docs/runbooks/frontend-development.md).
Быстрый запуск — `make frontend-up` (API на `127.0.0.1:8081`, без Telegram и AI).

Полная спецификация web-клиента — в
[`docs/front-end/`](docs/front-end/README.md): архитектура, сущности, каталог
запросов, функциональные блоки, карты последовательностей, локальные макеты,
quality matrix, реестр API/design-разрывов и
[backlog задач по 2–4 дня](docs/front-end/TASKS.md).
